AI & GenAI Projects

Codewalk ↗: AI Code Intelligence Platform · demo video
Indexing, RAG-based chat, and multi-agent code review over a repository, as one product
  • Multi-agent review: a diff is partitioned into batches and a pool of review agents works them in parallel (4 concurrent), each batch returning findings plus its own coverage verdict, so a review with a failed batch reports as incomplete instead of passing. Findings are grounded against the checked-out revision before storage, then written back as PR comments and a check run.
  • RAG-based chat: a question expands into 2 to 4 angles, then one shared gather pulls from a graph symbol walk and a batched vector search in a single embedding request; every candidate is scored 0 to 10 in one ranking call, which is the only step that drops evidence, and a failed ranking keeps everything. Answers cite the file and symbol.
  • Indexing: tree-sitter parses 14 languages into a symbol graph and parent-child chunks, embedded under an adaptive rate governor, then promoted by an atomic swap so readers only ever open a finished index and a retry resumes rather than re-embedding files it already paid for.

Stack: Python, FastAPI, PostgreSQL, Redis, tree-sitter, ChromaDB, DuckDB, Next.js, Docker, Go edge gateway

VoiceFlow ↗: Real-Time Voice AI Platform · demo video
